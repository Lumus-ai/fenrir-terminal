# Фенрир Терминал — наш терминал, не Оркестра

**Статус: мы ушли от Оркестры и создали свой терминал.**
Обозначено 06.11.2026 по слову Shadow: «я про наш терминал, мы же ушли от оркестры и создали свой».

## Что это такое — простыми словами

Оркестра была чужая программа: тяжёлый Bun-сервер, мёртвый совет,
финалы терялись, лимиты падали. Мы от неё ушли.

**Фенрир Терминал — наша собственная система**, которой Фенрир
работает вместо Оркестры. Это не промпт в bash и не баннер —
это весь рабочий терминал: движок + команды + сервер.

## Состав

| Часть | Что это | Где |
|---|---|---|
| Движок | Fenrir-Orchestra — прямые вызовы к Lix/Klinch/Anymodel, фолбэк, 6 параллельных воркеров, ответы сразу на диск | `~/workspace/fenrir-orchestra/` |
| Терминал | Имя, баннер, промпт `🐺 fenrir@terminal`, команда `fenrir` | `~/workspace/fenrir-terminal/` |
| Сервер | Лёгкий Python-сервер, ~24 МБ, `127.0.0.1:4097` | `fenrir up` / `fenrir down` |

## Имя и версия

- **Имя:** Фенрир Терминал (Fenrir Terminal)
- **Версия:** 1.3 — 06.11.2026 (см. [CHANGELOG.md](CHANGELOG.md))
- **Хозяин:** Shadow. **Оператор:** Фенрир.
- **Девиз:** без простоев, без чужих серверов.

## Что нового в 1.3 (06.11.2026, сильный агент)

- Агент: новые инструменты `edit_file` (замена точного фрагмента,
  отказ при 0 или >1 совпадении), `search` (regex по папке),
  `run_tests` (py_compile + pytest).
- Маршрутизация: код — klinch7/gpt-6-luna (доказано делает tool_calls)
  с фолбэком на klinch6 и живые Lix; текст — Lix qwen3.8-max первый.
  Мёртвые модели Lix и klinch/klinch2 в цепочках отсутствуют.
- Очередь задач агента: `--file tasks.jsonl`, лог на задачу, summary.json.
- Верификация по умолчанию: агент сам проверяет файлы на диске
  (HTML — начало/конец, единственность закрывающих тегов, дубли id;
  Python — компиляция) и дописывает, пока не станет чисто.
- `fenrir agent` — команда терминала вместо длинной строки запуска.

## Что нового в 1.2 (06.11.2026, надёжность)

- Watchdog-cron каждые 5 минут (`fenrir-orchestra-watchdog`): следит
  за serve и сам поднимает его при падении.
- `fenrir doctor` — самопроверка: serve, свежесть probe, RAM, диск,
  дедлайн Lix. Вывод OK/FAIL по пунктам.
- `fenrir limits` — лимиты всех ключей Klinch одной таблицей +
  остаток дней Lix.
- `fenrir usage` — токены за день по провайдерам (из runs/*/meta.json),
  пишет `state/usage-<дата>.json`.
- Probe честно показывает Lix: если перепроверка мёртвой модели упала,
  а живая ответила — провайдер alive, а не dead.
- Единый User-Agent `fenrir-agent/1.0` во всех запросах движка.

## Что нового в 1.1 (06.11.2026)

- `ram_guard()` — статус памяти: OK ≥500 МБ, WARN 300–499, CRITICAL <300.
- `lix_countdown()` — дней/часов до дедлайна Lix (09.11.2026).
- `health_summary()` — сводка probe по провайдерам из health JSON
  (починена: исходный код от модели итерировал dict как список).
- `bin/ram-watchdog.sh` — предупреждение в `logs/ram-warnings.log`,
  если доступной RAM < 300 МБ (`fenrir watchdog`).
- `fenrir_agent.py` — агент с циклом инструментов: модель сама пишет
  файлы (write_file/read_file/list_dir, только внутри рабочей папки).
  По умолчанию klinch7/gpt-6-luna. Проверен живьём на test-agent.txt.

Код ram_guard/lix_countdown/watchdog — ответы прямых моделей Lix
(qwen3.8-max), проверены живьём. Честный чейнджлог — в CHANGELOG.md:
в v1.1 вошли только проверенные вещи, без выдуманных улучшений.

## Команды терминала

- `fenrir status` — память, оркестра, Lix, сводка probe
- `fenrir ram` — кто ест память (+ статус ram_guard)
- `fenrir health` — сводка probe по провайдерам
- `fenrir watchdog` — проверка RAM, запись предупреждения в лог
- `fenrir probe` — живы ли модели
- `fenrir orchestra` — статус движка
- `fenrir up` / `fenrir down` — поднять/остановить сервер
- `fenrir doctor` — самопроверка (serve, probe, RAM, диск, Lix)
- `fenrir limits` — лимиты ключей Klinch + остаток Lix
- `fenrir usage` — токены за день по провайдерам
- `fenrir agent --task "..." --workdir <папка>` — агент с циклом инструментов
- `fenrir agent --file tasks.jsonl` — очередь задач агента
- `fenrir agent --task "..." --workdir <папка> --kind text` — текстовая задача (Lix первый)

## Чем отличается от Оркестры

- Оркестра: Bun-сервер 344 МБ, совет мёртв, финалы на 6144 токена терялись.
- Фенрир Терминал: Python 24 МБ, совета нет вообще — консилиум из 6 воркеров,
  ответы по 2000 токенов сразу на диск, Lix первый до 09.11.2026.
